# Booking API Documentation

## Overview
The Booking API allows lecturers to create room bookings with time conflict checking and proper authorization.

## Endpoints

### Create Room Booking
```
POST /rooms/{room_id}/booking
```

Creates a new booking for a specific room.

### Get Room Booking
```
GET /rooms/booking/{booking_id}
```

Retrieves booking information by booking ID.

## Authentication
Requires `role` header with value `lecturer`:
```
role: lecturer
```

**Role Required:** `lecturer` (only lecturers can create bookings)

## Request

### Path Parameters
- `room_id` (string): The room identifier (e.g., "401")

### Request Body
```json
{
  "user_id": "U2025120010",       // String, required (User ID of lecturer)
  "date": "2025-12-10",           // String, required (YYYY-MM-DD format)
  "start_time": "13:00",          // String, required (HH:MM format)
  "end_time": "15:00",            // String, required (HH:MM format)
  "course_id": "CO-2017",         // String, required
  "course_name": "Data Structure & Algorithm", // String, required
  "notes": "Lab session, bilingual" // String, optional
}
```

## Responses

### ✅ Success (201 Created)
```json
{
  "booking_id": "book1",          // String, auto-generated by backend
  "room_id": "401",               // String, from path parameter
  "user_id": "U2025120010",       // String, from request
  "date": "2025-12-10",
  "start_time": "13:00",
  "end_time": "15:00",
  "course_id": "CO-2017",
  "course_name": "Data Structure & Algorithm",
  "notes": "Lab session, bilingual"
}
```

### ❌ Unauthorized (401)
When a non-lecturer tries to create a booking:
```json
{
  "error": {
    "code": "UNAUTHORIZED",
    "message": "Only lecturers can create room bookings"
  }
}
```

### ❌ Time Conflict (409)
When the room is already booked for the requested time:
```json
{
  "error": {
    "code": "ROOM_ALREADY_BOOKED",
    "message": "Room is not available from 13:00 to 15:00"
  }
}
```

### ❌ Internal Server Error (500)
When there's a problem checking room availability:
```json
{
  "error": {
    "code": "ROMS_SERVICE_ERROR",
    "message": "Unable to check room availability"
  }
}
```

## Implementation Details

### Files Created
1. **`app/schemas/booking.py`** - Pydantic models for request/response
2. **`app/routers/booking.py`** - Booking endpoint implementation
3. **`app/database/db_client.py`** - Added `get_bookings_collection()` function

### Time Conflict Detection
The API checks for overlapping bookings using MongoDB queries:
- New booking starts during an existing booking
- New booking ends during an existing booking
- New booking completely contains an existing booking

### Database Schema
Bookings are stored in the `bookings` collection:
```json
{
  "_id": ObjectId,
  "booking_id": "book1",
  "room_id": "401",
  "user_id": "U2025120010",
  "date": "2025-12-10",
  "start_time": "13:00",
  "end_time": "15:00",
  "course_id": "CO-2017",
  "course_name": "Data Structure & Algorithm",
  "notes": "Lab session, bilingual",
  "created_at": "2025-12-06T10:30:00Z"
}
```

## Get Booking Endpoint

### Request
- **Method:** GET
- **Path:** `/rooms/booking/{booking_id}`
- **Authentication:** None required

### Path Parameters
- `booking_id` (string): The booking identifier (e.g., "book1")

### Responses

#### ✅ Success (200 OK)
```json
{
  "booking_id": "book1",
  "room_id": "401",
  "user_id": "U2025120010",
  "date": "2025-12-10",
  "start_time": "13:00",
  "end_time": "15:00",
  "course_id": "CO-2017",
  "course_name": "Data Structure & Algorithm",
  "notes": "Lab session, bilingual"
}
```

#### ❌ Not Found (404)
When the booking doesn't exist:
```json
{
  "error": {
    "code": "BOOKING_NOT_FOUND",
    "message": "Booking ID could not be found in ROMs System"
  }
}
```

#### ❌ Internal Server Error (500)
When there's a database error:
```json
{
  "error": {
    "code": "DATABASE_ERROR",
    "message": "Unable to retrieve booking information"
  }
}
```

## Testing

### Prerequisites
1. Start the FastAPI server:
   ```bash
   python -m app.main
   ```

2. The server should be running at `http://localhost:8000`

### Using the Test Script
Run the provided test script:
```bash
python test_booking.py
```

This will test:
- ✅ Successful booking creation
- ❌ Unauthorized access (student role)
- ❌ Time conflict detection
- ✅ Non-conflicting booking in different time slot

### Manual Testing with curl

#### Create a booking
```bash
curl -X POST http://localhost:8000/rooms/401/booking \
  -H "role: lecturer" \
  -H "Content-Type: application/json" \
  -d '{
    "user_id": "U2025120010",
    "date": "2025-12-10",
    "start_time": "13:00",
    "end_time": "15:00",
    "course_id": "CO-2017",
    "course_name": "Data Structure & Algorithm",
    "notes": "Lab session"
  }'
```

#### Get a booking
```bash
curl -X GET http://localhost:8000/rooms/booking/book1
```
